# Working agreement

- After making changes, always commit and push them to `origin`
  (`git push origin master`). Do not wait to be asked.
- Only commit changes you actually made; keep commit messages concise.
- `todo.lua` and `tests/ui_test.lua` are generated by `build.py`; edit
  `src/*.lua` and run `python3 build.py`.
- Run `./run-tests.sh` after changes; it builds and runs both test suites.
